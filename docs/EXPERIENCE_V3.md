# LOWKYZ — The Living Signal

Une identité entre développement Full-Stack, son et direction artistique. Le portfolio raconte une pratique réelle, sans inventer de résultats ni transformer le parcours en interface de recrutement.

## Direction

Ivoire `#eeece4`, encre `#20221f`, orange signal `#f25229`. Barlow Condensed pour les grandes compositions éditoriales, Geist pour la lecture, monospace pour les repères. Filets, surfaces ouvertes et contrastes francs remplacent les cartes et les effets de verre.

Le hero assemble une identité LOWKYZ dominante, une promesse lisible, des CTA immédiats et une sculpture 3D progressive. Sa famille de courbes lie précision mathématique et intuition musicale. Intro réelle, passable et rejouable, sans blocage.

## Continuité

Intro → Work → Engineering → Journey → About → Contact. Les ancres historiques `profil`, `projets`, `stack`, `experience`, `about`, `contact` restent valides. Le fil permanent indique le chapitre actif ; sur mobile il devient une partition horizontale compacte.

Work devient une galerie directionnelle à captures authentiques. Engineering relie technologies et réalisations ; Journey visualise les dates sourcées. About croise portrait et pratiques ; Contact reçoit la signature 3D. Les huit études de cas partagent six scènes, le canvas, les ancres et les captures agrandissables.

Le moteur `lib/use-scroll-narrative.ts` centralise progression, jonctions et environnement via l’unique boucle de `lib/motion-runtime.ts`.
